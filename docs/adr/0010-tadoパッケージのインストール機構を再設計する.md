# tado パッケージのインストール機構を再設計する

`skillsDir` 配下への `bun add` による分散インストール（`package.json` / `bun.lock` / `node_modules/` の汚染、ツール×スコープ最大 8 箇所への分散）を廃止し、`tado install` / `tado update` コマンドと `paths.ts` の分散前提ロジックを削除する。CLI バイナリはグローバルインストールに準拠したまま維持し、ワークフローからの `import from "tado"` 解決のため `{TADO_HOME}/node_modules/tado` にもライブラリを配置する。後方互換や移行サポートは不要（既存ユーザー 1 名のため）。
