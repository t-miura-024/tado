# TUIフレームワークにOpenTUIを採用する

Bun専用の `tado` に、同一ターミナル内で動作する参照専用ダッシュボードをTUIとして追加する必要があった。Bun上で動作し、Box/ScrollView等のコンポーネントで2カラムレイアウトとフロー図を描画できるフレームワークとして、OpenTUIを採用する。

代替として `ink`（Reactベース）はNode依存が強くBunとの親和性が低く、`blessed` はメンテナンスが停滞しており、自前実装は描画・キー操作・レイアウトの全てを自作するコストが高いため不採用とした。
