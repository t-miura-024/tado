# ダッシュボードはBun.serveのローカルWebサーバー＋1秒ポーリングで提供する

GUIダッシュボードは `tado dashboard` 実行時にBun.serveでランダム空きポートのローカルHTTPサーバーを起動し、ブラウザで `http://localhost:<port>` を開く方式とする。APIは `GET /api/snapshot` で `loadDashboardSnapshot` 結果をJSON返却し、クライアントは1秒ごとにpollingする。

固定ポートは衝突時のリトライが複雑、SSE/WebSocketは参照専用の読み取り専用スコープ（ADR-0013）には過剰。1秒ポーリングは現行TUIと同等の更新性を担保しつつサーバーをステートレスに保てるため採用。終了はCtrl+Cでサーバー停止とし、ブラウザClose連動は行わない。
