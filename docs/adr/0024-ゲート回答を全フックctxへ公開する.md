# ゲート回答を全フック ctx へ公開する

ゲート回答（`gateAnswers`）は `ConditionCtx` にのみ公開されており、`buildPrompt` / `check` / `beforeStep` / `afterStep` から参照できなかった。このためワークフローは回答を後続ステップのプロンプトへ渡す手段を持たず、エージェントが `~/.tado/workflow.db` の `gate_events` を直接読む事例が発生した。全フック ctx の共通フィールドとして `gateAnswers` と `sessionId` を公開し、読み出しの公式経路を ctx に一本化する。`gateAnswers` の意味論は「ゲートごとの最新試行の回答（approve / revise を問わず、設問単位の `GateAnswer`）」とし、DB スキーマは公開契約に含めない。
