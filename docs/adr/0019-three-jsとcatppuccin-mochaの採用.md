# Three.jsによる装飾的3D表現とCatppuccin Mocha配色を採用する

GUIダッシュボードの表現力を高めるため、Three.jsを装飾的背景（Catppuccin Mocha配色のパーティクル/グラデーション/アンビエント）とフロー図ノード間の3Dライン装飾に活用する。全面3D化やフロー図自体の完全3D再実装は情報密度とアクセシビリティを損なうため行わない。

Catppuccin Mochaはコントラストと可読性に優れ、Tailwind/shadcn/uiのテーマと一貫する。Three.jsが無効でも情報表示は完全に機能するフォールバックを保証する。
