# ADR-0001: セッション状態 DB の単一ファイル化（~/.tado/workflow.db）

- Status: Accepted
- Date: 2026-07-31

## 背景

セッションごとの DB が各リポジトリの `tmp/tado/` に散在し、ダッシュボード（#6）での網羅的確認が困難。保存先が cwd 依存のため、実行場所によってセッションが別リポジトリに分かれる問題もあった。

## 決定

全セッションの状態を `~/.tado/workflow.db` 単一の SQLite ファイルに格納する。セッションディレクトリ（成果物・artifact DB）も `~/.tado/sessions/{sessionId}/` に移す。保存先は `TADO_HOME` 環境変数で上書き可能。既存 DB の移行は行わない。WAL モード + `busy_timeout` で複数プロセスからの同時アクセスを吸収する。バックアップ機構は設けない。

## 代替案

- `--base-dir` のデフォルト値を `~/.tado` に変更: 実運用で `--base-dir` を変えると DB が再び散らばるため不採用
- 旧 DB の自動マイグレーション: 不透明な自動処理を避けるため不採用
- バックアップ機構: 履歴 DB は再実行で再現可能な情報が大半であり、個人使用では保守コストが見合わないため不採用

## 結果・影響

状態 DB と成果物が cwd 非依存になり、複数リポジトリ横断で 1 箇所から管理できる。Issue #6 のダッシュボード実装の前提となる。既存セッション（旧レイアウト）は新バージョンから参照・再開できない（残置・非管理）。
